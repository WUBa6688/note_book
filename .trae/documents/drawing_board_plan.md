# Zhuibook 画板功能需求文档 V2

> 本文档基于用户最新需求重新整理。**核心变化**：画板与笔记是**两个平行的主视图**，由主窗口顶部按钮切换；画板界面与功能参照 Windows 自带「画图」（mspaint.exe）；嵌入笔记只是画板的众多功能之一，并非唯一目的。

---

## 一、需求背景与目标

### 1.1 用户原始需求
1. **画板与笔记是独立的**：主窗口顶部提供两个按钮「📝 笔记」「🖌 画板」，点击切换主视图，二者互不干扰。
2. **画板内容可嵌入笔记正文**：作为画板的众多功能之一（非唯一目的），可将当前画板导出为图片并插入到笔记光标处。
3. **画板参照 Windows 自带画图**：包括界面布局（功能区 / 调色板 / 画布）、工具种类、交互方式均贴近系统原生画图软件。

### 1.2 设计目标
| 目标 | 说明 |
|------|------|
| 视图独立 | 笔记视图与画板视图平级，通过顶部 Tab/按钮切换，不互相嵌套 |
| 体验贴近原生 | 画板 UI 参照 Windows 画图（顶部功能区 + 调色板 + 状态栏 + 画布） |
| 功能完备 | 提供与 mspaint 相当的工具集，足以独立作为绘图工具使用 |
| 可选联动 | 画板通过「插入笔记」按钮将内容以图片形式嵌入当前笔记 |
| 主题一致 | 画板支持应用现有主题（matcha / lemon / fog 及其深色变体） |

### 1.3 非目标（本次不做）
- 不做笔记内嵌矢量图形的二次编辑（嵌入后即为普通图片）
- 不做图层管理、手写板压感
- 不做多画板会话（一次仅一个画板实例）

## 二、主窗口架构改造

### 2.1 当前架构
```
MainWindow
  └── QSplitter (Horizontal)
       ├── Sidebar         （笔记列表/分类/搜索）
       └── MarkdownEditor  （编辑器 + 工具栏 + 大纲面板）
```

### 2.2 改造后架构
```
MainWindow
  ├── TopTabBar（新增）       ← 顶部模式切换栏
  │     [📝 笔记]  [🖌 画板]
  └── ContentStack (QStackedWidget)  ← 视图容器
       ├── Page 0: NoteView      ← 原有 QSplitter（Sidebar + Editor）
       └── Page 1: DrawingBoardView  ← 新增画板主视图
```

### 2.3 切换行为规则
| 规则 | 说明 |
|------|------|
| 默认视图 | 启动后默认显示「笔记」视图 |
| 数据保留 | 切换视图时，**两侧状态都保留**（笔记内容、画板内容均不丢失） |
| 侧边栏归属 | 笔记列表仍属于「笔记」视图，画板视图不再显示笔记列表 |
| 关闭行为 | 主窗口关闭时，若画板有未保存内容，弹窗询问是否保存为文件 |
| 主题联动 | 切换主题时画板一并应用 |

### 2.4 TopTabBar 视觉示意
```
┌────────────────────────────────────────────────────────┐
│  📝 笔记    🖌 画板                                       │  ← 顶部 Tab 栏（高度 ~36px）
├────────────────────────────────────────────────────────┤
│                                                        │
│              （下方为对应视图内容）                        │
│                                                        │
└────────────────────────────────────────────────────────┘
```
- 当前选中 Tab 带下划线高亮（颜色取主题 `accent`）
- 未选中 Tab 使用 `text_secondary` 色
- 整条 Tab 栏背景使用 `bg_secondary`
- 拖拽时不允许切换 Tab（避免误触）

### 3.2 与 Windows 画图的对齐点
| Windows 画图特性 | 本画板对应实现 |
|------------------|----------------|
| 顶部 Ribbon 功能区 | 工具分组（剪贴板 / 绘图 / 形状 / 颜色） |
| 左侧工具竖排 | 合并到顶部工具区（保持横向 FlowLayout，遵循项目已有约定） |
| 底部调色板 | 顶部调色板区，两行布局（预设色 + 自定义） |
| 双色机制（颜色1/颜色2） | 保留：左键=主色，右键=次色 |
| 状态栏坐标显示 | 实现：实时显示鼠标坐标、画布尺寸、缩放比例 |
| 画布可滚动+缩放 | 实现：QGraphicsView 自带滚动 + 自定义缩放 |
| 拖拽改变画布大小 | 本次不做（仅预设固定尺寸） |

## 四、画板功能详细清单

### 4.1 工具集（核心功能）

#### 4.1.1 绘图工具
| 工具 | 图标 | 快捷键 | 说明 |
|------|------|--------|------|
| 画笔 | ✏️ | P | 自由绘制，支持粗细 1~30px，抗锯齿 |
| 喷枪 | 💧 | A | 喷雾式绘制，随机散点 |
| 刷子 | 🎨 | B | 较粗的画笔，预设几种刷头形状（圆/方/斜） |
| 橡皮擦 | 🧽 | E | 擦除为画布背景色 |
| 取色器 | 💉 | I | 从画布拾取颜色为主色 |
| 填充 | 🪣 | G | 油漆桶，洪水填充算法 |
| 文字 | 🅰️ | T | 点击画布弹出输入框，支持字体/大小/颜色 |
| 选择-矩形 | ⬜ | R | 框选区域，可移动/删除选中内容 |
| 选择-自由 | ✂️ | L | 自由形状选区 |

#### 4.1.2 形状工具
| 形状 | 图标 | 说明 |
|------|------|------|
| 直线 | 📏 | 两点直线，按 Shift 锁定 45° |
| 曲线 | 〰️ | 三点贝塞尔曲线 |
| 矩形 | ▭ | 支持空心/实心/描边粗细 |
| 圆角矩形 | ▢ | 同上，圆角半径可调 |
| 椭圆 | ⬜ | 支持空心/实心 |
| 三角形 | ◢ | 等腰三角形 |
| 星形 | ⭐ | 五角星 |
| 箭头 | ➡️ | 带箭头线，箭头大小可调 |
| 对话框 | 💬 | 漫画对话框形状 |

#### 4.1.3 操作功能
| 操作 | 图标 | 快捷键 | 说明 |
|------|------|--------|------|
| 撤销 | ↩ | Ctrl+Z | 撤销上一步，最多 50 步 |
| 重做 | ↪ | Ctrl+Y | 恢复撤销 |
| 清空 | 🗑 | Ctrl+Shift+Del | 清空整个画布（需二次确认） |
| 复制 | 📋 | Ctrl+C | 复制选区到剪贴板 |
| 粘贴 | 📋 | Ctrl+V | 粘贴剪贴板内容 |
| 剪切 | ✂️ | Ctrl+X | 剪切选区 |
| 全选 | ⬜ | Ctrl+A | 全选画布 |

### 4.2 颜色系统
- **主色（颜色1）**：左键绘制使用，默认黑色 `#000000`
- **次色（颜色2）**：右键绘制使用，默认白色 `#FFFFFF`
- **预设调色板**：参照 Windows 画图的 20 种常用色
  ```
  黑 灰 深红 红 橙 黄 浅绿 绿 青 蓝 深蓝 紫 粉 棕 白
  浅灰 浅红 浅黄 浅绿 浅蓝
  ```
- **自定义颜色**：点击「自定义颜色...」打开 `QColorDialog`
- **当前色显示**：两个色块叠放显示主/次色，点击切换激活色

### 4.3 视图功能
| 功能 | 快捷键 | 说明 |
|------|--------|------|
| 放大 | Ctrl++ | 每次放大 25%，最大 800% |
| 缩小 | Ctrl+- | 每次缩小 25%，最小 25% |
| 100% | Ctrl+0 | 恢复原始大小 |
| 适应窗口 | Ctrl+1 | 画布自适应视口 |

### 4.4 嵌入笔记功能（次要功能）
> 此功能仅为画板的众多功能之一，非画板的唯一目的。

| 入口 | 说明 |
|------|------|
| 「插入到笔记」按钮 | 顶部工具区右侧，独立按钮 |
| 触发条件 | 必须有当前打开的笔记（否则按钮禁用，提示"请先在笔记视图打开一篇笔记"） |
| 数据流 | 画板 → 渲染为 QPixmap → 保存为 PNG → 插入笔记光标处 |
| 文件位置 | `~/.zhuibook/assets/note_{note_id}_images/drawing_{timestamp}.png` |
| 插入语法 | `![画板截图](图片相对路径)` |
| 行为 | 插入后不自动切换到笔记视图，保留在画板继续编辑 |

## 五、数据流与存储

### 5.1 画板会话生命周期
```
应用启动
  └─ 默认显示笔记视图
  └─ 画板视图未初始化（懒加载，首次切换时创建）

用户首次点击「🖌 画板」
  └─ 创建 DrawingBoardView 实例（加入 QStackedWidget）
  └─ 初始化空白画布 800×600

用户切换回「📝 笔记」
  └─ 画板内容保留在内存（不销毁）
  └─ 笔记视图照常工作

用户关闭主窗口
  └─ 若画板有未保存内容 → 弹窗询问「保存为 PNG / 丢弃 / 取消关闭」
  └─ 笔记内容照常保存流程
```

### 5.2 嵌入笔记的图片存储
- 沿用现有 `core/database.py` 中的 `get_assets_dir(note_id)` 机制
- 文件命名：`drawing_{YYYYMMDDHHMMSS}_{6位随机}.png`
- 笔记内引用相对路径：`assets/note_{id}_images/drawing_xxx.png`

### 5.3 画板独立保存
- 画板额外提供「保存为文件」按钮（Ctrl+S），将画板导出为独立 PNG 文件
- 默认保存路径：用户上次保存目录或桌面
- 与「插入到笔记」是两个独立功能

## 六、技术方案

### 6.1 技术选型
| 组件 | 选型 | 理由 |
|------|------|------|
| 画布框架 | `QGraphicsScene` + `QGraphicsView` | 支持矢量元素、便于撤销重做、自带缩放滚动 |
| 图形元素 | `QGraphicsPathItem` / `QGraphicsLineItem` / `QGraphicsRectItem` 等 | Qt 内置图形项，性能好 |
| 自由绘制 | `QGraphicsPathItem` + `QPainterPath` | 平滑曲线 |
| 填充 | `QImage` 像素级洪水填充 | 算法简单可靠 |
| 导出图片 | `QGraphicsScene.render()` → `QPixmap` → `QImage::save()` | Qt 原生支持 |
| 撤销栈 | `QUndoStack` + 自定义 `QUndoCommand` 子类 | Qt 原生命令模式 |

### 6.2 新增文件
| 文件 | 职责 |
|------|------|
| `ui/drawing_board.py` | 画板主视图（DrawingBoardView）+ 画布 + 工具栏 |
| `ui/drawing_tools.py` | 工具基类与各工具实现（画笔/形状/橡皮/填充等） |
| `ui/drawing_commands.py` | 撤销/重做命令封装 |
| `ui/top_tab_bar.py` | 主窗口顶部 Tab 切换栏组件 |

### 6.3 修改文件
| 文件 | 修改内容 |
|------|------|
| `ui/main_window.py` | 将原 QSplitter 包装为 NoteView，新增 QStackedWidget + TopTabBar，处理切换逻辑 |
| `ui/theme.py` | 新增画板视图、顶部 Tab 栏、调色板的 QSS 样式 |
| `core/database.py` | 新增 `save_drawing_to_note_assets(note_id, pixmap)` 工具函数（可选，也可直接写在 drawing_board.py） |

### 6.4 模块间依赖
```
main_window.py
   ├── ui/top_tab_bar.py        （新）
   ├── ui/sidebar.py            （不变）
   ├── ui/editor.py             （不变）
   └── ui/drawing_board.py      （新）
         ├── ui/drawing_tools.py    （新）
         ├── ui/drawing_commands.py （新）
         └── core/database.py       （沿用 get_assets_dir）
```

### 6.5 主题适配
- 画板工具栏背景：使用 `bg_secondary`
- 画布背景：固定白色（即使深色主题也保持白色画布，符合 Windows 画图习惯）
- 工具按钮 hover/active 态：使用 `accent` + `accent_hover`
- 调色板边框：使用 `border_color`

## 七、UI 主题与样式约定

遵循项目 memory 中已有的硬约束：
- 工具区使用 **FlowLayout** 自动换行，避免按钮被省略号截断
- 所有圆角统一 8~10px
- 工具按钮使用 QSS state 选择器（hover/pressed/checked）
- 深色主题下文字对比度 ≥ 4.5:1（WCAG AA）
- 工具栏阴影：`blurRadius=18, yOffset=2, alpha=30`
- 主题切换时画板所有子组件同步刷新

## 九、待用户确认事项

在进入实施阶段前，请用户确认以下几点：

1. **顶部 Tab 位置**：Tab 栏放在主窗口最顶部（覆盖 sidebar + editor 全宽），还是放在 sidebar 之上？
   - **方案 A（推荐）**：Tab 栏覆盖全宽，画板视图独立（不含 sidebar），最大化画板空间
   - **方案 B**：Tab 栏仅放在右侧内容区上方，sidebar 始终可见（画板视图与笔记共用 sidebar 区域）

2. **画板默认尺寸**：画布默认 800×600 是否合适？是否需要更大（如 1280×720）？

3. **画板主题联动**：深色主题下画布是否保持白色？
   - **方案 A（推荐）**：画布始终白色（贴近 Windows 画图）
   - **方案 B**：跟随主题变深色

4. **首次实现范围**：是否需要一次性实现所有 9 种形状工具？还是先实现基础 6 种（画笔/橡皮/直线/矩形/椭圆/文字），其余后续迭代？
