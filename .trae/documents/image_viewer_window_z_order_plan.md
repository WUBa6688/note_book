# 图片查看器窗口层级交互 — 修复方案

## 需求理解

用户需要的是最基础的窗口交互行为（类微信图片查看器）：
- **点击主编辑器（图一）** → 主编辑器显示在最前面
- **点击图片查看器（图二）** → 图片查看器显示在最前面
- 两个窗口通过点击自然切换前后层级，由 **Windows 原生窗口管理** 控制

## 问题根源

当前代码存在两个核心问题：

### 问题 1：`WindowStaysOnTopHint` 强制置顶
`__init__` 第 1170 行默认给图片查看器加了 `WindowStaysOnTopHint`，这使得它**永远**在主窗口之上，无法通过点击主窗口将其降到后面。

### 问题 2：事件过滤器手动 `self.lower()`
`eventFilter` 中手动调用 `self.lower()` 来模拟降级，但这与 Windows 原生窗口管理冲突，导致行为不稳定。

## 修改方案

### 核心思路

回归 **Windows 原生窗口管理机制**：两个独立的 Non-modal 窗口，点击谁谁就在最前面。固定按钮仅控制"是否置顶到所有窗口之上"。

### 修改点清单

| # | 文件 | 位置 | 修改内容 |
|---|------|------|---------|
| 1 | `editor.py` | `__init__` L1168-1170 | **移除**默认 `WindowStaysOnTopHint`，改为普通窗口 |
| 2 | `editor.py` | `__init__` L1174 | `_pinned = False`（默认不固定，即普通窗口） |
| 3 | `editor.py` | `__init__` L1176-1179 | **移除**事件过滤器安装代码（Windows 原生处理） |
| 4 | `editor.py` | `__init__` L1242-1243 | 固定按钮初始状态改为未固定（📍），Tooltip 改为"点击固定窗口" |
| 5 | `editor.py` | `_toggle_pin` L1432-1463 | **简化**：仅切换 `WindowStaysOnTopHint`，移除 `lower()/raise_()/activateWindow()` 等手动层级操作 |
| 6 | `editor.py` | `eventFilter` L1469-1475 | **移除整个方法**（不再需要） |
| 7 | `editor.py` | `closeEvent` L1477-1482 | **移除整个方法**（不再需要清理事件过滤器） |

### 详细逻辑

```
默认状态（未固定）:
  - 窗口 Flags: Window | WindowTitleHint | WindowMinMaxButtonsHint | WindowCloseButtonHint
  - 无 WindowStaysOnTopHint
  - 行为：与主编辑器平级，点击谁谁在前（Windows 原生）
  - 按钮：📍（灰色，Tooltip: "点击固定窗口"）

固定状态:
  - 窗口 Flags: 上述 + WindowStaysOnTopHint
  - 行为：始终在最前面（即使切换到其他应用也在上面）
  - 按钮：📌（金色，Tooltip: "窗口已固定，点击取消固定"）

点击主编辑器 → Windows 自动将主窗口提到最前
点击图片查看器 → Windows 自动将图片查看器提到最前
```

### 保留的功能

- ✅ 单例模式（一篇笔记只允许一个图片查看器）
- ✅ 任务栏最小化/最大化/关闭按钮
- ✅ 图片缩放、拖拽、上下张切换
- ✅ 点击笔记中的图片复用查看器
- ✅ 固定按钮切换置顶状态
- ✅ 导航按钮（◀▶）、缩略图、旋转、缩放等工具栏功能

## 风险评估

- **风险等级**：低
- **改动范围**：仅 `ImageViewerDialog` 类内部，不影响 `MarkdownEditor`
- **兼容性**：完全兼容现有功能
- **注意事项**：`setWindowFlags` 后需 `show()` + `restoreGeometry()` 保持窗口位置

## 验证步骤

1. 打开笔记中的图片 → 图片查看器以普通窗口形式显示
2. 点击主编辑器 → 主编辑器显示在最前，图片查看器在后面
3. 点击图片查看器可见部分 → 图片查看器显示在最前
4. 点击 📍 固定按钮 → 图片查看器置顶（📌图标，金色）
5. 固定状态下点击主编辑器 → 图片查看器保持置顶
6. 点击 📌 取消固定 → 恢复普通窗口行为
7. 最小化图片查看器 → 缩到任务栏
8. 关闭图片查看器 → 正常关闭
