# Zhuibook 画板 UI 重构方案（预览 + 选型）

> 针对当前界面“拥挤、混乱、缺乏层次”的反馈，提供两种截然不同的视觉方案供选择。

---

## 方案 A：极简现代风（Modern Minimal）

**设计理念**：参考 Figma / Sketch / Windows 11 画图，追求极简、专业、高信息密度。适合生产力导向。

### 布局预览图

```mermaid
graph TD
    subgraph 顶部工具栏 (固定高度)
        direction LR
        A[◻️  文件]
        B[✏️  绘制]
        C[◯  形状]
        D[🎨 颜色]
        E[🔍 视图]
        F[状态：就绪]
    end

    subgraph 左侧垂直工具栏 (宽 56px)
        direction TB
        L1[画笔]
        L2[喷枪]
        L3[刷子]
        L4[橡皮]
        L5[取色]
        L6[填充]
        L7[文字]
        L8[分隔线]
        L9[选择]
        L10[矩形]
        L11[自由]
    end

    subgraph 主画布区
        direction LR
        G["[垂直比例尺]"] --- H["画布 800×600"] --- I["[水平比例尺]"]
    end

    subgraph 底部状态栏
        S1[坐标: 120, 85]
        S2[缩放: 100%]
        S3[工具: 画笔]
        S4[提示: Ctrl+S 保存]
    end

    顶部工具栏 -- "文件/绘制/形状/颜色/视图 Tab" --> 左侧垂直工具栏
    顶部工具栏 -- "点击 Tab 动态切换" --> 左侧垂直工具栏
    左侧垂直工具栏 -- "展开" --> 主画布区
    主画布区 --> 底部状态栏
```

### 视觉规格

| 元素 | 规格 |
|------|------|
| 顶部栏高度 | 48px，固定 |
| Tab 标签 | 宽 80px，图标+文字，圆角 6px |
| 左侧栏宽度 | 56px，仅显示图标 |
| 左侧按钮 | 40×40px 图标按钮，圆角 8px |
| 按钮间距 | 4px |
| 选中态 | 主色背景 + 白色图标 + 左侧 3px 色条 |
| 画布圆角 | 0px（直角，专业感） |
| 画布外背景 | 浅灰 `#F5F5F5` |
| 字体 | 12px，微软雅黑 |
| 字号层级 | Tab 13px / 按钮 12px / 状态栏 11px |

### 配色方案（以 Matcha 主题为例）

```
背景:          #F5F5F5 (浅灰)
工具栏背景:    #FFFFFF (纯白)
Tab 背景:      #F8F8F8 (浅灰)
Tab 选中:      #FFFFFF (纯白 + 底部 2px 主色下划线)
按钮默认:      transparent
按钮悬停:      #F0F0F0 (浅灰)
按钮选中:      #5A9E7E (主色) + #FFFFFF (白图标)
边框:          #E0E0E0 (极浅灰)
```

### 优点
- ✅ 专业感强，适合办公/生产力场景
- ✅ 左侧垂直工具栏承载所有绘图/选择工具，不占画布空间
- ✅ Tab 切换分组，默认只显示 5 个 Tab，极简不拥挤
- ✅ 高信息密度，操作路径短

### 缺点
- ❌ 左侧工具栏默认仅显示图标，需要 tooltip 记忆功能
- ❌ 视觉相对“冷硬”，缺乏温度

## 方案 B：柔和卡片风（Soft Card）

**设计理念**：参考 Procreate / Notion / Apple Notes，追求柔和、友好、有温度。适合创意导向。

### 布局预览图

```mermaid
graph TD
    subgraph 顶部卡片区 (宽度自适应，圆角 16px)
        direction TB
        subgraph 第一行：快捷操作
            direction LR
            A1[🏠 插入笔记]
            A2[💾 保存]
            A3[↶ 撤销]
            A4[↷ 重做]
            A5[🗑️ 清空]
        end
        subgraph 第二行：工具分组
            direction LR
            B1["🖊 绘制 [画笔][喷枪][刷子][橡皮]"]
            B2["⚪ 形状 [矩形][椭圆][三角][箭头]"]
            B3["🎨 颜色 [色板] [粗细 ▬▬●▬▬]"]
            B4["🔍 视图 [100%][适应][滚轮:开]"]
        end
    end

    subgraph 画布区 (圆角 20px，大阴影)
        direction TB
        C1["[水平比例尺]"]
        C2["画布 800×600 (白色圆角)"]
        C3["[垂直比例尺]"]
    end

    subgraph 状态栏 (圆角 12px)
        direction LR
        D1[坐标: 120, 85]
        D2[缩放: 100%]
        D3[工具: 画笔]
    end

    顶部卡片区 -- "大圆角卡片" --> 画布区
    画布区 -- "嵌入" --> 顶部卡片区
    顶部卡片区 -- "嵌套卡片" --> 状态栏
```

### 视觉规格

| 元素 | 规格 |
|------|------|
| 顶栏圆角 | 16px（大圆角，柔和） |
| 画布圆角 | 20px（大圆，友好） |
| 画布阴影 | blurRadius=24, yOffset=8, alpha=0.15 |
| 按钮圆角 | 10px（圆润） |
| 按钮 padding | 10px 16px（宽松） |
| 按钮间距 | 12px（宽松） |
| 色板格子 | 28×28px（大色块，易点击） |
| 字号层级 | 分组标题 13px / 按钮 13px / 状态栏 12px |

### 配色方案

```
背景:          #F2F7F0 (抹茶绿主色背景)
顶栏卡片:      #FFFFFF (白色)
画布:          #FFFFFF (白色圆角)
画布阴影:      rgba(0,0,0,0.08)
按钮默认:      #FFFFFF + #D6E0D1 边框
按钮悬停:      #E7EEE3 (浅绿灰)
按钮选中:      #5A9E7E (主色) + #FFFFFF (白字)
分组标题:      #5A9E7E (主色) + 13px 加粗
色板格子:      28×28px 圆角 6px
```

### 优点
- ✅ 视觉柔和友好，适合创意/绘图场景
- ✅ 大按钮 + 大间距，低认知负担
- ✅ 大阴影 + 大圆角，层次感强
- ✅ 跨平台字体渲染一致（文字工具名不依赖图标）

### 缺点
- ❌ 占用空间大，画布区域相对较小
- ❌ 视觉不够紧凑，专业感稍弱

---

## 方案对比总结

| 维度 | 方案 A（极简现代） | 方案 B（柔和卡片） |
|------|------------------|------------------|
| 风格 | 扁平、直角、专业 | 圆润、柔和、友好 |
| 目标用户 | 办公/生产力 | 创意/手绘 |
| 信息密度 | 高 | 低 |
| 学习成本 | 中（需记忆图标） | 低（文字+图标） |
| 画布占比 | 大（工具栏窄） | 中（工具栏宽） |
| 实现难度 | 中（需自定义左侧栏） | 低（在现有基础上优化） |
